## 📖 Conceito

`derivedStateOf` cria um estado cujo valor é DERIVADO de outros estados. Ele recalcula só quando as fontes mudam, e só avisa quem o lê quando o RESULTADO muda.

Sem ele, você recalcularia o valor derivado a cada recomposição, e recomporia quem o lê mesmo quando o resultado não mudou. Para uma soma leve a diferença é pequena; para um cálculo caro sobre uma lista grande, é o que evita trabalho repetido.

:::caution Armadilha
`derivedStateOf` também precisa de `remember`, senão é recriado a cada recomposição e perde a graça. Na demo, a lista de tarefas é o estado-fonte; o "total" é derivado dela. Adicione e remova itens e veja o total acompanhar.
:::

## 💻 Código de Referência

```kotlin title="ui/lessons/L17DerivedState.kt"
@Composable
fun L17DerivedState(onBack: () -> Unit) {
    var tarefas by remember { mutableStateOf(listOf("Estudar Compose", "Fazer o exercício")) }
    var nova by remember { mutableStateOf("") }
    val total by remember { derivedStateOf { tarefas.size } }

    LessonScaffold(
        title = "derivedStateOf",
        notice = "O 'total' é derivado da lista, não guardado à parte. Adicione e " +
            "remova tarefas: o total é recalculado a partir do estado-fonte.",
        onBack = onBack
    ) {
        Column(
            modifier = Modifier.fillMaxWidth(),
            verticalArrangement = Arrangement.spacedBy(8.dp)
        ) {
            Text("total de tarefas: $total", style = MaterialTheme.typography.titleMedium)

            Row(
                modifier = Modifier.fillMaxWidth(),
                horizontalArrangement = Arrangement.spacedBy(8.dp),
                verticalAlignment = Alignment.CenterVertically
            ) {
                OutlinedTextField(
                    value = nova,
                    onValueChange = { nova = it },
                    label = { Text("nova tarefa") },
                    singleLine = true,
                    modifier = Modifier.weight(1f)
                )
                Button(
                    onClick = {
                        if (nova.isNotBlank()) {
                            tarefas = tarefas + nova.trim()
                            nova = ""
                        }
                    }
                ) { Text("add") }
            }

            tarefas.forEach { tarefa ->
                Row(
                    modifier = Modifier.fillMaxWidth(),
                    horizontalArrangement = Arrangement.SpaceBetween,
                    verticalAlignment = Alignment.CenterVertically
                ) {
                    Text(text = tarefa, modifier = Modifier.padding(vertical = 4.dp))
                    TextButton(onClick = { tarefas = tarefas - tarefa }) { Text("remover") }
                }
            }
        }
    }
}
```

## 🧪 Experimente

- Abra o app e vá em **Estado avançado → derivedStateOf**.
- Digite uma tarefa e toque em "add": o total sobe sem que você guarde esse número em lugar nenhum.
- Toque em "remover" numa tarefa e veja o total descer junto — ele é sempre recalculado a partir da lista, nunca guardado à parte.
- No código, repare que `total` só existe dentro do `remember { derivedStateOf { ... } } `: tirar o `remember` faria o derivado ser recriado a cada recomposição.
