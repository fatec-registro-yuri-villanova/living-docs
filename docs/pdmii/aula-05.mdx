## 🎯 Objetivo

Construir os blocos fundamentais de uma interface mobile interativa:
- **`StitchCard`** → container reutilizável para exibição em listas dinâmicas.
- **`StitchTextField`** → input controlado com estados visuais de foco e erro.

- **`LazyColumn`** → renderização performática de coleções de dados.
- **`LazyVerticalGrid`** → grid responsivo com múltiplas colunas.

## 🌿 Fluxo de Navegação

O app agora abre diretamente na tela de Login. Após o submit simulado, o usuário é redirecionado para o **Showcase** via `navController.navigate("showcase")`.

```
[ Login ] ──→ (submit) ──→ [ Showcase / LazyColumn + LazyVerticalGrid ]
                                     │
                              (Voltar para Login)
```

A configuração do `NavHost` vive em `MainActivity.kt`:

```kotlin title="MainActivity.kt"
val navController = rememberNavController()

NavHost(navController = navController, startDestination = "login") {
    composable("login") {
        LoginScreen(
            onLoginSuccess = {
                navController.navigate("showcase") {
                    popUpTo("login") { inclusive = true } // Remove login do back stack
                }
            }
        )
    }
    composable("showcase") {
        ShowcaseScreen(
            onBackToLogin = {
                navController.navigate("login") {
                    popUpTo("showcase") { inclusive = true }
                }
            }
        )
    }
}
```

:::tip Por que `popUpTo` com `inclusive = true`?
- `navController.navigate("showcase")` → mantém o Login na pilha (usuário pode voltar).
- `popUpTo("login") { inclusive = true }` → **remove** o Login da pilha. O usuário não consegue "voltar" para o Login com o botão físico depois de entrar. ✅
:::

## 📖 Recapitulação: State no Compose

Diferente do React Native, no Compose o estado é **observado** e dispara recomposições automáticas:

| Hook | Sobrevive a recomposição? | Sobrevive a rotação de tela? |
|------|--------------------------|------------------------------|
| `mutableStateOf(T)` | ❌ | ❌ |
| `remember { mutableStateOf(T) }` | ✅ | ❌ |
| `rememberSaveable { mutableStateOf(T) }` | ✅ | ✅ |

```kotlin
// Estado local simples — perde o valor ao recompor
var nome = mutableStateOf("")

// Estado que sobrevive a recomposições (maioria dos casos)
var nome by remember { mutableStateOf("") }

// Estado que sobrevive a rotação de tela
var nome by rememberSaveable { mutableStateOf("") }
```

:::info Nesta aula usamos ViewModel + StateFlow
Para lógica de negócio (validação, loading, navegação), elevamos o estado para um **ViewModel**. A tela (`Screen`) fica o mais **stateless** possível, apenas observando e disparando eventos.
:::

### `StitchCard` — Container para Listas

```kotlin title="ui/components/StitchCard.kt"
@Composable
fun StitchCard(
    onClick: (() -> Unit)? = null,  // null = card não clicável
    modifier: Modifier = Modifier,
    containerColor: Color = Surface,
    content: @Composable ColumnScope.() -> Unit
) {
    ElevatedCard(
        onClick = { onClick?.invoke() },
        enabled = onClick != null,  // desabilita o ripple se não clicável
        modifier = modifier,
        colors = CardDefaults.elevatedCardColors(containerColor = containerColor),
        shape = RoundedCornerShape(12.dp),
        elevation = CardDefaults.elevatedCardElevation(
            defaultElevation = 2.dp,
            pressedElevation = 6.dp
        ),
        content = content
    )
}
```

### `StitchTextField` — Input com Estado Visual

```kotlin title="ui/components/StitchTextField.kt"
@Composable
fun StitchTextField(
    value: String,
    onValueChange: (String) -> Unit,
    label: String,
    modifier: Modifier = Modifier,
    placeholder: String? = null,
    isError: Boolean = false,
    errorMessage: String? = null,
    secureTextEntry: Boolean = false,
    keyboardOptions: KeyboardOptions = KeyboardOptions.Default,
    visualTransformation: VisualTransformation = VisualTransformation.None
) {
    Column(modifier = modifier) {
        OutlinedTextField(
            value = value,
            onValueChange = onValueChange,
            label = { Text(label) },
            placeholder = placeholder?.let { { Text(it) } },
            isError = isError,
            modifier = Modifier.fillMaxWidth(),
            shape = RoundedCornerShape(12.dp),
            visualTransformation = visualTransformation,
            keyboardOptions = keyboardOptions,
            singleLine = true
        )
        if (isError && errorMessage != null) {
            Text(
                text = errorMessage,
                color = StitchError,
                style = MaterialTheme.typography.bodySmall,
                modifier = Modifier.padding(start = 8.dp, top = 4.dp)
            )
        }
    }
}
```

**Uso com validação de senha:**

```kotlin
StitchTextField(
    label = "Senha",
    value = uiState.password,
    onValueChange = { viewModel.onPasswordChange(it) },
    secureTextEntry = true,
    visualTransformation = PasswordVisualTransformation(),
    keyboardOptions = KeyboardOptions(
        keyboardType = KeyboardType.Password,
        imeAction = ImeAction.Done
    ),
    isError = uiState.error?.contains("6 caracteres") == true,
    errorMessage = uiState.error
)
```

:::caution `secureTextEntry` vs `PasswordVisualTransformation`
No Compose, o parâmetro `secureTextEntry` do nosso componente serve apenas como documentação semântica. A máscara real dos caracteres é feita por `PasswordVisualTransformation()` passado em `visualTransformation`.
:::

### `LoginUiState` e `LoginViewModel`

```kotlin title="ui/screens/auth/LoginViewModel.kt"
data class LoginUiState(
    val email: String = "",
    val password: String = "",
    val isLoading: Boolean = false,
    val error: String? = null,
    val isLoginSuccess: Boolean = false  // dispara navegação via LaunchedEffect
)

class LoginViewModel : ViewModel() {

    private val _uiState = MutableStateFlow(LoginUiState())
    val uiState: StateFlow<LoginUiState> = _uiState.asStateFlow()

    fun onEmailChange(newValue: String) {
        _uiState.update { it.copy(email = newValue, error = null) }
    }

    fun onPasswordChange(newValue: String) {
        _uiState.update { it.copy(password = newValue, error = null) }
    }

    fun onLoginClick() {
        val email = _uiState.value.email
        val password = _uiState.value.password

        if (!email.contains("@")) {
            _uiState.update { it.copy(error = "Digite um e-mail válido") }
            return
        }

        if (password.length < 6) {
            _uiState.update { it.copy(error = "Mínimo 6 caracteres") }
            return
        }

        viewModelScope.launch {
            _uiState.update { it.copy(isLoading = true, error = null) }
            delay(1500) // Simulação de rede
            _uiState.update { it.copy(isLoading = false, isLoginSuccess = true) }
        }
    }
}
```

### `imePadding` — Ergonomia Mobile no Compose

O equivalente Compose do `KeyboardAvoidingView` do React Native:

```kotlin title="ui/screens/auth/LoginScreen.kt"
@Composable
fun LoginScreen(onLoginSuccess: () -> Unit, viewModel: LoginViewModel = viewModel()) {
    val uiState by viewModel.uiState.collectAsState()

    // LaunchedEffect observa isLoginSuccess e dispara navegação sem efeito colateral na composição
    LaunchedEffect(uiState.isLoginSuccess) {
        if (uiState.isLoginSuccess) onLoginSuccess()
    }

    Box(
        modifier = Modifier
            .fillMaxSize()
            .padding(24.dp)
            .imePadding() // ← equivalente ao KeyboardAvoidingView
    ) {
        // Conteúdo do formulário
    }
}
```

:::tip `imePadding()` vs `KeyboardAvoidingView`
| React Native | Compose |
|---|---|
| `<KeyboardAvoidingView behavior="padding">` | `.imePadding()` no Modifier |
| Requer configuração por plataforma (iOS/Android) | Funciona automaticamente em ambas |
:::

### `LazyVerticalGrid` — Grid Responsivo

```kotlin
LazyVerticalGrid(
    columns = GridCells.Fixed(2),           // 2 colunas fixas
    modifier = Modifier
        .fillMaxWidth()
        .height(340.dp),                    // altura fixa (necessário dentro de LazyColumn)
    horizontalArrangement = Arrangement.spacedBy(12.dp),
    verticalArrangement = Arrangement.spacedBy(12.dp),
    userScrollEnabled = false               // scroll delegado ao LazyColumn pai
) {
    items(MOCK_COURSES) { course ->
        StitchCard(modifier = Modifier.fillMaxWidth()) {
            Column(modifier = Modifier.padding(12.dp)) {
                Text(text = course.title, fontWeight = FontWeight.Bold)
                Spacer(modifier = Modifier.height(6.dp))
                Badge(
                    containerColor = MaterialTheme.colorScheme.secondaryContainer,
                    contentColor = MaterialTheme.colorScheme.onSecondaryContainer
                ) {
                    Text(course.level)
                }
            }
        }
    }
}
```

:::caution `LazyVerticalGrid` dentro de `LazyColumn`
Lazy layouts aninhados causam erro de tamanho ilimitado no Compose. A solução é:
1. Definir `height(Xdp)` fixo no `LazyVerticalGrid`
2. Setar `userScrollEnabled = false` para delegar o scroll ao pai
:::

| `LazyColumn` | `LazyVerticalGrid` |
|---|---|
| Lista vertical simples | Grid com N colunas |
| `items(list)` | `items(list)` + `columns = GridCells.Fixed(N)` |
| `FlatList` no React Native | `FlatList numColumns={N}` no React Native |
