## 🔀 Como Usar

```bash
# Clone o repositório da disciplina
git clone https://github.com/fatec-registro-yuri-villanova/<repo>.git

# Mude para a branch da aula
git checkout aula-01

# Siga os exercícios na documentação
```

:::tip Branches = Aulas
Cada `aula-XX` é uma branch com o código daquela aula. A documentação referencia esse código diretamente.
:::
