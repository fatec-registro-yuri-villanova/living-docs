## 📖 Conceito

O **CMS (Content Management System)** é uma aplicação Desktop construída com Compose for Desktop que permite gerenciar cursos, aulas e quizzes do MergeSkills. Ela roda na JVM e reutiliza os modelos do módulo `shared/`.

A aula 13 estabelece a **infraestrutura base**: janela principal maximizada, roteamento entre `LoginScreen` e `CmsScreen`, e autenticação com verificação de `role = "admin"`.

## 🔑 AuthViewModel

Gerencia o estado de autenticação. Usa `multiplatform-settings` (não DataStore) para persistência local.

```kotlin title="desktopMain/.../viewmodel/AuthViewModel.kt"
class AuthViewModel(
    private val repository: UserRepository,
    private val settings: Settings
) {
    sealed class AuthUiState {
        object Idle : AuthUiState()
        object Loading : AuthUiState()
        data class Success(val user: User) : AuthUiState()
        data class Error(val message: String) : AuthUiState()
        object NotAdmin : AuthUiState()   // usuário existe mas não é admin
    }

    fun login(email: String, password: String) {
        scope.launch {
            _authState.value = AuthUiState.Loading
            repository.login(LoginRequest(email, password))
                .onSuccess { response ->
                    val user = response.user
                    if (user != null && user.role == "admin") {
                        saveSession(user)
                        _authState.value = AuthUiState.Success(user)
                    } else {
                        _authState.value = AuthUiState.NotAdmin
                    }
                }
                .onFailure { error ->
                    _authState.value = AuthUiState.Error(error.message ?: "Erro desconhecido")
                }
        }
    }
}
```

:::caution Estado `NotAdmin`
Quando um usuário sem `role = "admin"` tenta logar, o estado fica `NotAdmin` — **não** `Success`. A `LoginScreen` exibe uma mensagem específica sem navegar para o CMS.
:::

## 🖥️ LoginScreen

Layout centralizado com `Card` de 400dp. Reage reativamente ao estado do `AuthViewModel`.

```kotlin title="desktopMain/.../features/auth/LoginScreen.kt"
@Composable
fun LoginScreen(viewModel: AuthViewModel, onLoginSuccess: () -> Unit) {
    val authState by viewModel.authState.collectAsState()

    LaunchedEffect(authState) {
        if (authState is AuthViewModel.AuthUiState.Success) onLoginSuccess()
    }
    // Card 400dp centralizado com campos E-mail, Senha, mensagens de erro e botão "Entrar"
}
```

## 🚪 Main.kt — Roteamento

A troca de tela é feita via `mutableStateOf<Screen>` — sem `NavController`.

```kotlin title="desktopMain/.../main.kt"
sealed class Screen {
    object Login : Screen()
    object Cms : Screen()
}

fun main() {
    val koin = startKoin { modules(desktopAppModule) }.koin
    val authViewModel = koin.get<AuthViewModel>()

    application {
        var currentScreen by remember {
            val initial: Screen = if (runBlocking { authViewModel.isLoggedIn() }) Screen.Cms else Screen.Login
            mutableStateOf(initial)
        }

        Window(
            onCloseRequest = ::exitApplication,
            title = "MergeSkills CMS",
            state = rememberWindowState(placement = WindowPlacement.Maximized)
        ) {
            MaterialTheme(colorScheme = darkColorScheme()) {
                when (currentScreen) {
                    Screen.Login -> LoginScreen(viewModel = authViewModel,
                        onLoginSuccess = { currentScreen = Screen.Cms })
                    Screen.Cms -> CmsScreen(authViewModel = authViewModel,
                        onLogout = { currentScreen = Screen.Login })
                }
            }
        }
    }
}
```
