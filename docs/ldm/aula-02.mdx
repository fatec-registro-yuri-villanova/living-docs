# Aula 02: Largura, colunas e quebra de linha

:::info 🔀 Código da Aula
- **Ponto de partida:** o estado ao fim da aula anterior
- **Gabarito final:** `git checkout main`
:::

## 📖 Conceito

A impressora não sabe o que é uma "palavra". Ela recebe uma sequência de caracteres e imprime até a linha acabar — aí corta, no meio de qualquer coisa, sem aviso. Quem decide *onde* quebrar o texto antes de mandar para o hardware é o app.

De onde vêm os 32 caracteres por linha? A Lintian LT-8359 imprime com a Font A, cujos glifos padrão medem 12×24 dots. A largura útil do papel é 384 dots:

```
384 dots ÷ 12 dots/caractere = 32 caracteres por linha
```

`Impressora.DOTS_LARGURA = 384` é uma inferência a partir dessa conta, não um valor lido de datasheet — a aula 15 confirma o número em papel com uma etiqueta de calibração impressa na própria impressora. Até lá, 384 é a melhor estimativa disponível.

Escala também entra na conta. Se o texto imprime em escala 2 (glifo com o dobro da largura), cabem só 16 caracteres na mesma linha física — a metade. `QuebraDeLinha.colunasPara(escala)` existe para essa divisão: `colunasPara(1)` devolve 32, `colunasPara(2)` devolve 16.

### Por que a regra mora num objeto isolado

`QuebraDeLinha` não faz parte do renderizador ESC/POS nem da tela. Ela é um objeto `commonMain` só com essas duas funções, sem dependência de nada. O motivo aparece só na aula 12: lá, um preview na tela vai mostrar ao usuário exatamente como a etiqueta vai sair impressa, quebrando o texto do mesmo jeito que a impressora quebra. Se a lógica de quebra do preview divergir um caractere sequer da lógica de quebra do renderizador, o preview passa a mentir — o que aparece na tela não é o que sai no papel. Colocar as duas em `QuebraDeLinha.quebrar()` e chamar essa única função dos dois lugares é o que impede a divergência.

## 🔴 O Teste

```kotlin title="shared/src/commonTest/kotlin/com/fatec/printec/etiqueta/QuebraDeLinhaTest.kt"
package com.fatec.printec.etiqueta

import kotlin.test.Test
import kotlin.test.assertEquals

class QuebraDeLinhaTest {

    @Test
    fun `texto menor que a largura fica em uma linha`() {
        assertEquals(listOf("bancada A"), QuebraDeLinha.quebrar("bancada A", 32))
    }

    @Test
    fun `texto com exatamente 32 caracteres nao quebra`() {
        val texto = "a".repeat(32)
        assertEquals(listOf(texto), QuebraDeLinha.quebrar(texto, 32))
    }

    @Test
    fun `texto com 33 caracteres quebra em duas linhas`() {
        val texto = "a".repeat(33)
        assertEquals(listOf("a".repeat(32), "a"), QuebraDeLinha.quebrar(texto, 32))
    }

    @Test
    fun `quebra preferencialmente no espaco entre palavras`() {
        val texto = "peca de reposicao para bancada central"
        assertEquals(
            listOf("peca de reposicao para bancada", "central"),
            QuebraDeLinha.quebrar(texto, 32),
        )
    }

    @Test
    fun `palavra maior que a linha e cortada em vez de sumir`() {
        val texto = "b".repeat(40)
        assertEquals(listOf("b".repeat(32), "b".repeat(8)), QuebraDeLinha.quebrar(texto, 32))
    }

    @Test
    fun `acentos contam como um caractere`() {
        // Na PC860 cada acentuada ocupa 1 byte, entao conta 1 coluna.
        val texto = "ação não coração"  // 16 caracteres
        assertEquals(listOf(texto), QuebraDeLinha.quebrar(texto, 16))
    }

    @Test
    fun `texto vazio produz uma linha vazia`() {
        assertEquals(listOf(""), QuebraDeLinha.quebrar("", 32))
    }

    @Test
    fun `escala dobrada reduz as colunas pela metade`() {
        assertEquals(32, QuebraDeLinha.colunasPara(1))
        assertEquals(16, QuebraDeLinha.colunasPara(2))
        assertEquals(8, QuebraDeLinha.colunasPara(4))
    }
}
```

## Passo 2 — QuebraDeLinha

```kotlin title="shared/src/commonMain/kotlin/com/fatec/printec/etiqueta/QuebraDeLinha.kt"
package com.fatec.printec.etiqueta

/**
 * Regra de quebra COMPARTILHADA entre o preview e o renderizador ESC/POS.
 * Se as duas divergirem, o WYSIWYG vira mentira — por isso mora num lugar só.
 */
object QuebraDeLinha {

    fun colunasPara(escala: Int): Int = Impressora.COLUNAS_BASE / escala.coerceAtLeast(1)

    fun quebrar(texto: String, colunas: Int): List<String> {
        if (texto.isEmpty()) return listOf("")

        val linhas = mutableListOf<String>()
        var restante = texto

        while (restante.isNotEmpty()) {
            if (restante.length <= colunas) {
                linhas += restante
                break
            }
            val janela = restante.substring(0, colunas + 1)
            val corte = janela.lastIndexOf(' ')
            if (corte <= 0) {
                // Palavra maior que a linha: corta na largura em vez de descartar.
                linhas += restante.substring(0, colunas)
                restante = restante.substring(colunas)
            } else {
                linhas += restante.substring(0, corte)
                restante = restante.substring(corte + 1)
            }
        }
        return linhas
    }
}
```

`quebrar()` percorre o texto em loop, cortando uma linha por vez, e cada volta cai em um de três casos:

- **Cabe na linha** — `restante.length <= colunas`: o resto inteiro vira a última linha e o loop termina.
- **Quebra no último espaço da janela** — quando não cabe, pega uma janela de `colunas + 1` caracteres, procura o último espaço nela (`lastIndexOf(' ')`) e corta ali, descartando o espaço.
- **Palavra maior que a linha** — se a janela não tem espaço nenhum (`corte <= 0`), não há onde quebrar por palavra. Em vez de descartar o excesso, o código corta exatamente na largura (`restante.substring(0, colunas)`) e continua processando o resto na próxima linha — nenhum caractere se perde.

`colunasPara(escala)` é a função que a seção anterior descreveu: `Impressora.COLUNAS_BASE / escala.coerceAtLeast(1)`. O `coerceAtLeast(1)` evita divisão por zero (ou resultado negativo) se algum chamador passar `escala <= 0` — a função se protege sozinha em vez de confiar que quem chama nunca vai errar.

## ⚠️ Atenção

A janela usada para procurar o espaço de corte é `colunas + 1` caracteres — **não** `colunas`. Repare na linha (já mostrada no Passo 2 acima): `val janela = restante.substring(0, colunas + 1)`.

O `+ 1` existe para cobrir o caso em que o espaço cai exatamente na fronteira da coluna 32. Se a janela fosse só `colunas` caracteres, um espaço na posição 32 nunca apareceria nela — a busca `lastIndexOf(' ')` não o enxergaria, e a função cairia no caso de "palavra maior que a linha", cortando no meio de uma palavra que na verdade termina exatamente ali. Trocar `colunas + 1` por `colunas` faz o texto perder efetivamente uma coluna de conteúdo útil toda vez que uma quebra cai bem na borda da linha — um bug sutil, porque a maioria dos textos de teste não bate exatamente no limite.
