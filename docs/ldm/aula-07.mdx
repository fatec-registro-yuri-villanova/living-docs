# Aula 07: Autenticação via Servidor

:::info 🔀 Branch da Aula
Esta aula refere-se à branch: **`aula-07`** — `git checkout aula-07`
:::

## 📖 Conceito

Diferente do fluxo focado exclusivamente no JWT pelo Ktor Plugin, exploraremos como criar rotas manuais e construir um serviço de autenticação onde validamos as credenciais (e-mail e senha) diretamente contra a tabela `users` do nosso provedor, devolvendo o modelo de _User_ com as DTOs de `AuthResponse`.

## 💻 Código de Referência

```kotlin title="server/.../routes/AuthRoutes.kt"
fun Route.authRoutes(supabase: SupabaseClient) {
    route("/auth") {
        post("/login") {
            val request = call.receive<LoginRequest>()
            val users = supabase.from("users").select {
                filter {
                    eq("email", request.email)
                    eq("password", request.password ?: "")
                }
            }.decodeList<User>()

            if (users.isNotEmpty()) {
                call.respond(AuthResponse(accessToken = "", user = users.first()))
            } else {
                call.respond(
                    HttpStatusCode.Unauthorized,
                    ApiError(code = "INVALID_CREDENTIALS", message = "E-mail ou senha incorretos")
                )
            }
        }
    }
}
```
