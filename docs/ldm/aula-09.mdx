# Aula 09: Gerenciamento e Upload de Arquivos

:::info 🔀 Branch da Aula
Esta aula refere-se à branch: **`aula-09`** — `git checkout aula-09`
:::

Iniciando o **Módulo 3**, abordaremos a integração do nosso Ktor Server com o Supabase Storage. O objetivo é implementar a funcionalidade de upload de imagens via Multipart, permitindo que os usuários salvem seus avatares de perfil (e posteriormente, administradores subam capas de cursos).

## 📖 DTOs Modelados em `StorageDTOs.kt`

Nossa comunicação flui entre o app e servidor padronizada, de forma simples com a resposta da URL:

```kotlin
@Serializable
data class UploadResponse(
    val url: String
)
```

## 🧪 Como Testar

Abra o seu terminal com o Ktor Server em execução (`http://localhost:8080`), e certifique-se de que você possui um arquivo de imagem na sua máquina local antes de rodar o comando:

<Tabs>
<TabItem value="curl" label="cURL">

```bash
# Simulação cURL de um arquivo de teste (Form-Data)
# Substitua "@/caminho/para/avatar.jpg" pelo caminho real da imagem no seu PC
curl -X POST http://localhost:8080/upload/avatar \
  -H "Accept: application/json" \
  -F "userId=20" \
  -F "file=@/caminho/para/avatar.jpg"
```

</TabItem>
<TabItem value="postman" label="Postman">
No Postman, crie uma rota POST para `http://localhost:8080/upload/avatar`.
1. Vá na aba `Body`.
2. Habilite a caixa `form-data`.
3. Adicione uma key `"userId"` do tipo **Texto**, enviando `20`.
4. Adicione uma key `"file"` do tipo **File** e arraste a imagem do seu computador para o botão!
</TabItem>
</Tabs>
